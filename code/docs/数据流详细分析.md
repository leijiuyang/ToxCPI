# ToxCPI 数据流详细分析（Binding任务）

## 一、特征提取模型总结

### 1.1 化学品特征提取模型

| 模型 | 预训练权重 | 输入 | 输出维度 | 用途 |
|------|-----------|------|----------|------|
| **ChemBERTa** | `seyonec/ChemBERTa-zinc-base-v1` | SMILES字符串 | 768→256 | 序列级分子表征 |
| **AttentiveFP** | 无（从头训练） | 原子特征(39d) | 256 | 原子级图结构表征 |
| **ToxAlert** | 无（可训练MLP） | ToxPrint+Benigni+EDC | 812→256 | 毒性结构警示特征 |

### 1.2 蛋白质特征提取模型

| 模型 | 预训练权重 | 输入 | 输出维度 | 用途 |
|------|-----------|------|----------|------|
| **ESM-2** | `facebook/esm2_t33_650M_UR50D` | 氨基酸序列 | 1280→256 | 残基级蛋白质表征 |
| **SimpleProteinEncoder** | 无（备选） | 氨基酸序列 | 256 | 轻量级备选编码器 |

## 二、化学品侧数据流（逐层维度变化）

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                    化学品编码详细流程（3个视图并行）                          │
└─────────────────────────────────────────────────────────────────────────────┘

输入: SMILES字符串列表 (batch_size个)
  例如: ["CCO", "CC(=O)O", "c1ccccc1"]

════════════════════════════════════════════════════════════════════════════════

【视图1: ChemBERTa编码】
┌─────────────────────────────────────────────────────────────────────────────┐
│ Step 1: Tokenization                                                       │
│   输入: ["CCO", "CC(=O)O", ...]                                            │
│   ↓                                                                        │
│   ChemBERTaTokenizer                                                       │
│   - 添加特殊标记: [CLS], [SEP], [PAD]                                      │
│   - 截断/padding到 max_length=512                                          │
│   ↓                                                                        │
│   输出: {                                                                  │
│     'input_ids': (batch, seq_len)      # token索引                        │
│     'attention_mask': (batch, seq_len)  # 1=真实token, 0=padding          │
│   }                                                                       │
│                                                                             │
│   示例: "CCO" → [CLS] C C O [SEP] [PAD] [PAD] ...                         │
│         input_ids = [0, 12, 12, 14, 2, 1, 1, ...]  (共512个)               │
├─────────────────────────────────────────────────────────────────────────────┤
│ Step 2: ChemBERTa Model                                                    │
│   输入: input_ids, attention_mask                                          │
│   ↓                                                                        │
│   ChemBERTa (12层Transformer, 每层768维)                                   │
│   - 冻结前6层，微调后6层                                                    │
│   - Layer 0-5: 冻结（requires_grad=False）                                │
│   - Layer 6-11: 可训练                                                     │
│   ↓                                                                        │
│   last_hidden_state: (batch, seq_len, 768)                                 │
├─────────────────────────────────────────────────────────────────────────────┤
│ Step 3: 提取表征                                                            │
│   cls_emb = last_hidden_state[:, 0, :]    # 取[CLS] token                  │
│           → (batch, 768)                                                  │
│                                                                             │
│   token_emb = last_hidden_state         # 所有token                        │
│            → (batch, seq_len, 768)                                          │
├─────────────────────────────────────────────────────────────────────────────┤
│ Step 4: 投影到统一维度                                                      │
│   proj: Linear(768 → 256)                                                  │
│   ↓                                                                        │
│   global_emb = proj(cls_emb)        → (batch, 256)                         │
│   token_emb = proj(token_emb)        → (batch, seq_len, 256)               │
└─────────────────────────────────────────────────────────────────────────────┘

【视图2: AttentiveFP编码】
┌─────────────────────────────────────────────────────────────────────────────┐
│ Step 1: SMILES → 分子图                                                     │
│   输入: SMILES字符串                                                        │
│   ↓                                                                        │
│   RDKit: MolFromSmiles()                                                   │
│   ↓                                                                        │
│   分子图:                                                                  │
│     - 节点: 原子 (n_atoms个)                                               │
│     - 边: 化学键                                                           │
│                                                                             │
│   示例: "CCO"  →  C-C-O                                                   │
│                节点: [C0, C1, O2]  (n_atoms=3)                             │
├─────────────────────────────────────────────────────────────────────────────┤
│ Step 2: 原子特征提取 (每个原子39维)                                         │
│   get_atom_features(atom) → 39维向量                                       │
│                                                                             │
│   特征组成:                                                                │
│   ├── 原子类型 one-hot (10维): C,N,O,S,F,Cl,Br,I,P,other                   │
│   ├── 度数 one-hot (6维): 0,1,2,3,4,5                                     │
│   ├── 形式电荷 one-hot (5维): -2,-1,0,1,2                                  │
│   ├── 杂化类型 one-hot (5维): SP,SP2,SP3,SP3D,SP3D2                        │
│   ├── 是否在环中 (1维)                                                      │
│   ├── 是否芳香 (1维)                                                        │
│   ├── 氢原子数 one-hot (5维): 0,1,2,3,4                                    │
│   ├── 手性 (2维)                                                           │
│   ├── 原子质量 (1维, 归一化)                                                │
│   ├── 范德华半径 (1维, 归一化)                                               │
│   └── 电负性 (1维, 归一化)                                                  │
│                                                                             │
│   node_feats: (batch, max_atoms, 39)                                        │
├─────────────────────────────────────────────────────────────────────────────┤
│ Step 3: 节点特征投影                                                         │
│   node_embedding: Linear(39 → 256)                                         │
│   ↓                                                                        │
│   h = ReLU(Dropout(node_embedding(node_feats)))                             │
│     → (batch, max_atoms, 256)                                              │
├─────────────────────────────────────────────────────────────────────────────┤
│ Step 4: 图注意力层 (num_layers=3)                                           │
│   for i in range(3):                                                       │
│     ├── MultiheadAttention(                                              │
│     │     embed_dim=256, num_heads=4,                                      │
│     │     query=h, key=h, value=h                                         │
│     │   )                                                                  │
│     │   ↓                                                                  │
│     │   h_attn: (batch, max_atoms, 256)                                   │
│     ├── LayerNorm(h + h_attn)  # 残差连接                                  │
│     └── h = LayerNorm输出                                                  │
│                                                                             │
│   输出: h: (batch, max_atoms, 256)                                          │
├─────────────────────────────────────────────────────────────────────────────┤
│ Step 5: 图级读出                                                             │
│   graph_feat = mean(h, dim=1)  # 平均池化                                  │
│             → (batch, 256)                                                 │
│                                                                             │
│   atom_feats = h  # 保留原子级表征                                          │
│             → (batch, max_atoms, 256)                                      │
└─────────────────────────────────────────────────────────────────────────────┘

【视图3: ToxAlert毒性特征编码】
┌─────────────────────────────────────────────────────────────────────────────┐
│ 预计算: 在Dataset初始化时已计算好                                           │
│                                                                             │
│ Step 1: ToxPrint特征 (729维)                                               │
│   输入: SMILES → RDKit Mol对象                                             │
│   ↓                                                                        │
│   ToxPrint特征组成:                                                         │
│   ├── Morgan Fingerprint (512维, radius=2)                                  │
│   ├── MACCS Keys (167维)                                                   │
│   └── 毒性相关描述符 (50维):                                                │
│       ├── 分子量, LogP, TPSA                                              │
│       ├── 氢键供体/受体数                                                   │
│       ├── 可旋转键数、环数                                                   │
│       └── 40种原子类型计数                                                 │
│   ↓                                                                        │
│   toxprint: (batch, 729)                                                   │
├─────────────────────────────────────────────────────────────────────────────┤
│ Step 2: Benigni-Bossa特征 (33维)                                           │
│   输入: RDKit Mol对象                                                       │
│   ↓                                                                        │
│   SMARTS模式匹配:                                                           │
│   - 硝基 [N+](=O)[O-]                                                      │
│   - 偶氮 N=N                                                               │
│   - 芳香胺 [NH2]c1ccccc1                                                   │
│   - ... (共33种致癌警示结构)                                               │
│   ↓                                                                        │
│   benigni: (batch, 33)  # 二元向量，0/1表示是否匹配                         │
├─────────────────────────────────────────────────────────────────────────────┤
│ Step 3: EDC内分泌干扰物特征 (50维)                                          │
│   输入: RDKit Mol对象                                                       │
│   ↓                                                                        │
│   SMARTS模式匹配50种EDC结构:                                               │
│   - 酚类: c1ccc(O)cc1                                                      │
│   - 邻苯二甲酸酯类                                                         │
│   - 多氯联苯类                                                             │
│   - 有机氯农药类                                                           │
│   - ...                                                                   │
│   ↓                                                                        │
│   edc: (batch, 50)  # 二元向量                                             │
├─────────────────────────────────────────────────────────────────────────────┤
│ Step 4: ToxAlert编码器                                                       │
│   ┌─────────────────────────────────────────────────────────────────────┐   │
│   │ toxprint → Linear(729→256) → ReLU → Dropout → Linear(256→128)       │   │
│   │                ↓                                                     │   │
│   │           h_tox: (batch, 128)                                        │   │
│   │                                                                     │   │
│   │ benigni → Linear(33→64) → ReLU → Linear(64→64)                      │   │
│   │                ↓                                                     │   │
│   │           h_ben: (batch, 64)                                         │   │
│   │                                                                     │   │
│   │ edc → Linear(50→64) → ReLU → Linear(64→64)                          │   │
│   │                ↓                                                     │   │
│   │           h_edc: (batch, 64)                                         │   │
│   └─────────────────────────────────────────────────────────────────────┘   │
│   ↓                                                                        │
│   concat(h_tox, h_ben, h_edc) → (batch, 128+64+64) = (batch, 256)           │
│   ↓                                                                        │
│   fusion: Linear(256→256) → LayerNorm → ReLU → Dropout                     │
│   ↓                                                                        │
│   tox_emb: (batch, 256)                                                    │
└─────────────────────────────────────────────────────────────────────────────┘

【多视图融合: MultiViewFusion】
┌─────────────────────────────────────────────────────────────────────────────┐
│ 输入:                                                                      │
│   h_seq: (batch, 256)    # ChemBERTa全局表征                               │
│   h_graph: (batch, 256)  # AttentiveFP图表征                               │
│   h_tox: (batch, 256)    # ToxAlert毒性表征                                │
│                                                                             │
│ Step 1: 拼接三个视图                                                         │
│   h_concat = cat([h_seq, h_graph, h_tox], dim=-1)                          │
│           → (batch, 256×3) = (batch, 768)                                  │
│                                                                             │
│ Step 2: 计算门控权重                                                         │
│   gate: Linear(768→256) → Tanh → Linear(256→3) → Softmax                    │
│   ↓                                                                        │
│   weights: (batch, 3)  # 三个视图的注意力权重，和为1                        │
│                                                                             │
│ Step 3: 加权融合                                                             │
│   h_fused = weights[:,0:1] * h_seq + weights[:,1:2] * h_graph              │
│            + weights[:,2:3] * h_tox                                        │
│          → (batch, 256)                                                    │
│                                                                             │
│ Step 4: 残差连接 + 层归一化                                                   │
│   h_residual = Linear(768→256)(h_concat)  → (batch, 256)                    │
│   h_out = LayerNorm(h_fused + h_residual)  → (batch, 256)                   │
│                                                                             │
│   chem_emb: (batch, 256)   # 最终化学品全局表征                              │
│   atom_emb: (batch, seq_len, 256)  # token级表征（来自ChemBERTa）            │
└─────────────────────────────────────────────────────────────────────────────┘
```

## 三、蛋白质侧数据流（逐层维度变化）

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                    蛋白质编码详细流程                                       │
└─────────────────────────────────────────────────────────────────────────────┘

输入: 蛋白质序列列表 (batch_size个)
  例如: ["MKTAYIAKQRQISFVKSHFSRQLEERLGL", ...]

════════════════════════════════════════════════════════════════════════════════

【ESM-2编码器】
┌─────────────────────────────────────────────────────────────────────────────┐
│ Step 1: Tokenization                                                       │
│   输入: ["MKTAYIAKQRQISFVKSHFSRQLEERLGL", ...]                             │
│   ↓                                                                        │
│   ESM-2 Tokenizer                                                          │
│   - 添加特殊标记: <cls>, <eos>, <pad>, <unk>                              │
│   - 截断/padding到 max_length=1024                                        │
│   ↓                                                                        │
│   输出: {                                                                  │
│     'input_ids': (batch, seq_len)                                         │
│     'attention_mask': (batch, seq_len)                                     │
│   }                                                                       │
│                                                                             │
│   氨基酸到token索引映射:                                                    │
│   M → 22, K → 17, T → 20, A → 5, Y → 24, I → 12, ...                     │
├─────────────────────────────────────────────────────────────────────────────┤
│ Step 2: ESM-2 Model                                                        │
│   模型架构: facebook/esm2_t33_650M_UR50D                                   │
│   ├── 33层Transformer                                                      │
│   ├── 隐藏维度: 1280                                                        │
│   ├── 注意力头: 20                                                          │
│   ├── 总参数量: 650M                                                        │
│   └── 冻结前20层，微调后13层                                                │
│                                                                             │
│   输入: input_ids, attention_mask                                          │
│   ↓                                                                        │
│   ESM-2 encoder (33层)                                                     │
│   │  ┌─────────────────────────────────────────────────────────────┐     │
│   │  │ Layer 0-19: 冻结                                              │     │
│   │  │ Layer 20-32: 可训练                                           │     │
│   │  │                                                               │     │
│   │  │ 每层包含:                                                      │     │
│   │  │   - MultiHeadAttention(d_model=1280, n_heads=20)              │     │
│   │  │   - FeedForwardNetwork(1280 → 5120 → 1280)                    │     │
│   │  │   - LayerNorm × 2                                              │     │
│   │  │   - Residual Connection × 2                                    │     │
│   │  └─────────────────────────────────────────────────────────────┘     │
│   ↓                                                                        │
│   hidden_states: (batch, seq_len, 1280)                                    │
├─────────────────────────────────────────────────────────────────────────────┤
│ Step 3: 提取表征                                                            │
│   cls_emb = hidden_states[:, 0, :]    # 取<cls> token                      │
│           → (batch, 1280)                                                 │
│                                                                             │
│   residue_emb = hidden_states          # 所有残基                          │
│              → (batch, seq_len, 1280)                                       │
├─────────────────────────────────────────────────────────────────────────────┤
│ Step 4: 投影到统一维度                                                      │
│   proj: Linear(1280 → 256)                                                 │
│   ↓                                                                        │
│   global_emb = proj(cls_emb)       → (batch, 256)                          │
│   residue_emb = proj(residue_emb)   → (batch, seq_len, 256)                │
│                                                                             │
│   输出:                                                                    │
│     prot_emb: (batch, 256)       # 蛋白质全局表征                           │
│     residue_emb: (batch, seq_len, 256)  # 残基级表征                       │
└─────────────────────────────────────────────────────────────────────────────┘
```

## 四、化学品-蛋白质交互建模（Bilinear Attention核心）

```
┌─────────────────────────────────────────────────────────────────────────────┐
│              Bilinear Attention 交互建模（核心创新）                        │
└─────────────────────────────────────────────────────────────────────────────┘

输入:
  H_atom: (batch, seq_len, 256)    # 化学品token级表征
  H_residue: (batch, seq_len, 256) # 蛋白质残基级表征

════════════════════════════════════════════════════════════════════════════════

【Bilinear Attention - 多头版本】
┌─────────────────────────────────────────────────────────────────────────────┐
│ 核心参数:                                                                  │
│   num_heads: 4                                                            │
│   W: (4, 256, 256)  # 4个可学习的双线性交互矩阵                             │
└─────────────────────────────────────────────────────────────────────────────┘

Step 1: 多头双线性注意力计算
┌─────────────────────────────────────────────────────────────────────────────┐
│ 对每个头 h ∈ {0,1,2,3}:                                                   │
│                                                                             │
│   score[h] = H_atom @ W[h] @ H_residue^T                                  │
│                                                                             │
│   详细维度:                                                                │
│     H_atom:      (batch, n_atoms, 256)                                     │
│     W[h]:        (256, 256)                                                │
│     H_residue:   (batch, n_residues, 256)                                  │
│                                                                             │
│   transformed = H_atom @ W[h]                                              │
│              → (batch, n_atoms, 256) @ (256, 256)                          │
│              → (batch, n_atoms, 256)                                       │
│                                                                             │
│   score[h] = transformed @ H_residue^T                                    │
│             → (batch, n_atoms, 256) @ (batch, 256, n_residues)            │
│             → (batch, n_atoms, n_residues)                                 │
│                                                                             │
│   A_multi: (batch, 4, n_atoms, n_residues)                                 │
│                                                                             │
│ 平均多头:                                                                  │
│   A = mean(A_multi, dim=1)  → (batch, n_atoms, n_residues)                 │
│                                                                             │
│   A[i,j] 表示: 第i个token与第j个残基的交互强度                               │
└─────────────────────────────────────────────────────────────────────────────┘

Step 2: 双向注意力归一化
┌─────────────────────────────────────────────────────────────────────────────┐
│ 原子视角: 每个原子关注哪些残基                                               │
│   A_atom = softmax(A / √256, dim=-1)                                       │
│          → (batch, n_atoms, n_residues)                                    │
│   每行和为1: Σ_j A_atom[i,j] = 1                                            │
│                                                                             │
│ 残基视角: 每个残基被哪些原子关注                                             │
│   A_residue = softmax(A^T / √256, dim=-1)                                  │
│             → (batch, n_residues, n_atoms)                                 │
│   每行和为1: Σ_i A_residue[j,i] = 1                                          │
└─────────────────────────────────────────────────────────────────────────────┘

Step 3: 双向加权聚合
┌─────────────────────────────────────────────────────────────────────────────┐
│ 原子聚合残基信息:                                                           │
│   h_atom_agg = A_atom @ H_residue                                          │
│              → (batch, n_atoms, n_residues) @ (batch, n_residues, 256)     │
│              → (batch, n_atoms, 256)                                       │
│                                                                             │
│   含义: 每个原子获得了关注残基的加权平均表征                                  │
│                                                                             │
│ 残基聚合原子信息:                                                           │
│   h_residue_agg = A_residue @ H_atom                                       │
│                → (batch, n_residues, n_atoms) @ (batch, n_atoms, 256)      │
│                → (batch, n_residues, 256)                                  │
│                                                                             │
│   含义: 每个残基获得了关注原子的加权平均表征                                  │
└─────────────────────────────────────────────────────────────────────────────┘

Step 4: 投影与全局池化
┌─────────────────────────────────────────────────────────────────────────────┐
│ 投影:                                                                      │
│   h_atom_proj = atom_proj(h_atom_agg)  # Linear(256→256)                   │
│                → (batch, n_atoms, 256)                                     │
│                                                                             │
│   h_residue_proj = res_proj(h_residue_agg)  # Linear(256→256)              │
│                  → (batch, n_residues, 256)                                │
│                                                                             │
│ 全局池化 (考虑mask):                                                        │
│   h_atom_global = mean(h_atom_proj, dim=1)                                 │
│                → (batch, 256)                                              │
│                                                                             │
│   h_residue_global = mean(h_residue_proj, dim=1)                            │
│                   → (batch, 256)                                           │
│                                                                             │
│   含义: 将所有原子/残基的聚合表征平均为全局交互特征                            │
└─────────────────────────────────────────────────────────────────────────────┘

Step 5: 交互特征融合
┌─────────────────────────────────────────────────────────────────────────────┐
│ 拼接双向交互特征:                                                           │
│   h_concat = cat([h_atom_global, h_residue_global], dim=-1)                 │
│            → (batch, 256+256) = (batch, 512)                               │
│                                                                             │
│ MLP融合:                                                                   │
│   h_interact = MLP(h_concat)                                               │
│                → Linear(512→512)                                           │
│                → LayerNorm(512)                                            │
│                → ReLU                                                      │
│                → Dropout(0.1)                                              │
│                → (batch, 512)                                              │
│                                                                             │
│   输出:                                                                    │
│     h_interact: (batch, 512)   # 最终交互特征                               │
│     A: (batch, n_atoms, n_residues)  # 注意力矩阵（可解释性）                │
└─────────────────────────────────────────────────────────────────────────────┘
```

## 五、预测头（Binding任务）

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                    BinaryPredictor 预测头                                   │
└─────────────────────────────────────────────────────────────────────────────┘

输入: h_interact (batch, 512)

┌─────────────────────────────────────────────────────────────────────────────┐
│ MLP分类器:                                                                 │
│   h = Linear(512→256)(h_interact)  → (batch, 256)                          │
│   h = LayerNorm(256)(h)                → (batch, 256)                       │
│   h = ReLU(h)                           → (batch, 256)                       │
│   h = Dropout(0.3)(h)                   → (batch, 256)                       │
│   h = Linear(256→128)(h)               → (batch, 128)                       │
│   h = ReLU(h)                           → (batch, 128)                       │
│   h = Dropout(0.15)(h)                  → (batch, 128)                       │
│   logits = Linear(128→1)(h)             → (batch, 1)                        │
│                                                                             │
│ 激活:                                                                      │
│   prob = sigmoid(logits)                  → (batch, 1)                        │
│                                                                             │
│ 输出:                                                                      │
│   {                                                                        │
│     'logits': (batch, 1),      # 原始logits                                │
│     'prob': (batch, 1),        # 结合概率 [0,1]                             │
│     'attention_matrix': (batch, n_atoms, n_residues)  # 注意力热图          │
│   }                                                                       │
└─────────────────────────────────────────────────────────────────────────────┘
```
