Only human_aop_proteins_multilabel.csv is read as an AOP mapping input. Do not copy

3. Representative fixed-weight evaluation

Example binding cold command (repeat with the task/split and original filenames in
code/manifests/weight_identity.csv and fixed_splits.csv):
  python code/inference/evaluate_fixed_checkpoint.py \
    --task binding --split cold --test-csv data/binding/test_cold.csv \
    --checkpoint runtime/weights/binding/fusion_cold_best.pth \
    --entity-cache runtime/entity_features.pt \
    --output-dir runtime/smoke_binding_cold --limit 32 --device cpu

Local validation used exact feature vectors for 192 fixed test records (32 per
model). No feature cache is included in the release. Provide a complete trusted
cache explicitly; --limit 32 repeats representative interface validation, while
--limit 0 evaluates all feature-eligible stored records and records exclusions.
No random split, rebalancing, deduplication or SMILES identity cleaning occurs.

To construct a full cache from trusted frozen feature dictionaries:
  python code/features/build_entity_cache.py \
    --compound-features runtime/pretrained_features/compound_features_bermol_tokens.pkl \
    --protein-features runtime/pretrained_features/protein_features_esm2_residues.pkl \
    --output runtime/entity_features.pt
This calls the existing FusionDataset.build_entity_tensors at max64/768. Do not
replace historical corrupt archives silently. Generated bytes will have new hashes.

Feature generation requires authorized BerMol code/weights and ESM-2. Read
code/third_party/BerMol/README.md. BerMolModel_base.pkl expected SHA256 is
afd1929fdbef6da110b5f4d0688a0f4a5f88fc3fb660bfcc1fb56e9624de38b1.
ESM-2 identity is esm2_t33_650M_UR50D, 33 layers, 650M parameters, residue dimension
1280; official source: https://github.com/facebookresearch/esm and model URL
https://dl.fbaipublicfiles.com/fair-esm/models/esm2_t33_650M_UR50D.pt . Neither upstream
weight is a trained ToxCPI classifier. Upstream weight generation/download was not
rerun. Cache identity and token/residue preprocessing must be retained.
extract_sequence_features.py now resolves data/output from the repository or
TOXCPI_BINDING_TABLE / TOXCPI_FEATURE_DIR and can use TOXCPI_ESM2_MODEL locally.
The fixed effect files contain no sequence field: extract_effect_features.py needs
TOXCPI_PROTEIN_SEQUENCE_CSV, a fixed annotation CSV with uniprot_id plus sequence or
protein_sequence. Missing/conflicting sequences halt; do not substitute current
UniProt sequences silently. Full feature regeneration remains unvalidated.

5. Analysis limits

The targeted historical sources under reproduction/source_references document
attribution, external direction, bootstrap, five-seed, LIT-PCBA and permutation
methods. They remain reference sources with missing portable input closures.
Do not claim that all SI analyses are runnable or re-executed. In particular,
six primary checkpoints are not the controlled five-seed checkpoints. Warm BPA-AR
attribution and calibrated cold external direction use different model/protocol
identities; neither replaces raw-probability Route 2 matching.
